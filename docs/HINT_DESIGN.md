# ジャンルヒント 設計メモ（未実装）

狙撃手が1ゲームに1回だけ、HPと引き換えにお題の「ジャンル」を見られる機能。
条件は持ち主と確認済み（2026-11-09）。実装時にこのメモの内容を SPEC.md に取り込み、DECISIONS.md に記録してから、このファイルを削除する。

## 1. ルール

| 項目                | 内容                                                                                                |
| ------------------- | --------------------------------------------------------------------------------------------------- |
| 使える人            | 狙撃手のみ（標的・観測手は使えない）                                                                |
| 使える時            | 自分の回答の番で、回答する前                                                                        |
| 回数                | 1人1ゲームに1回。延長戦・サドンデスに入っても回復しない                                             |
| 代償                | 使った狙撃手に 15 ダメージ（CONFIG で変更可）                                                       |
| 倍率                | ヒントのダメージには倍率をかけない（延長戦・サドンデスでも 15）。命中・誤射は従来どおり倍率がかかる |
| 見える範囲          | ジャンルはその場の全員に見える（射撃画面は全員に見せる画面のため）                                  |
| 使ったあと          | 撃つ（命中・誤射）かパスするかを選ぶ。パスしてもよい                                                |
| HP0 になったら      | 誤射と同じ扱い。その瞬間に脱落し、終了判定へ（自爆）                                                |
| 元に戻す            | ヒントの使用は取り消せない。使った時点で、その前の操作も「元に戻す」の対象から外れる                |
| 同じラウンドで2人目 | そのラウンドでジャンルがすでに公開されていれば、ヒントボタンは押せない（同じ情報に払わせないため）  |

戦略上の意味：ジャンルは全員に見えるので、使った本人が撃ち抜けなければ、ほかの狙撃手に有利な情報を渡すだけになる。使いどころが勝負になる。HPは見えないので、終盤は「使った瞬間に脱落するかもしれない」読み合いになる。

## 2. 画面

### 2.1 射撃画面（観測手が操作し、全員に見せる）

- **ヒントボタン**：命中・誤射・パスと並べて置く。押せるのは次のすべてを満たすときだけ。
  - 今回答する狙撃手がヒントをまだ持っている
  - このラウンドでジャンルがまだ公開されていない
  - このラウンドがまだ終わっていない
- **確認ダイアログ**：押すと次を表示し、「使う」か「キャンセル」を選ぶ。
  > ○○さんがヒントを使いますか？
  > 使うと 15 ダメージを受けます。HPが足りなければその場で脱落します。
  > この操作は元に戻せません。
- **ジャンルの表示位置**：公開済みヒント一覧のすぐ上に、そのラウンドが終わるまで常に表示する。
  > 🔍 ジャンル：生き物
  - 誰が使ったかは表示しない（その場の一大イベントなので覚えていられる。持ち主の判断）。
- **ヒントを持っているかの表示**：回答履歴の各狙撃手の名前の横に印を付ける（例：「🔍」）。使った人は印が消える。数値は出さない。

### 2.2 出題画面（標的）

- 任意出題では、お題の入力欄の下に **ジャンルの選択欄**（必須）を置く。未選択なら確定できない。
- ランダム出題では、辞書のカテゴリから自動で決まり、抽選結果と一緒に表示する（例：「動物 → ジャンル：生き物」）。
- 差し戻し後の書き直しでは、お題と同じくジャンルも変更できない。

### 2.3 承認画面（観測手）

- お題・カテゴリと並べてジャンルを表示する（観測手が不適切なジャンルに気づけるように）。ジャンルの誤りを理由に差し戻す仕組みは作らない（ヒント単位の差し戻しのみ）。

### 2.4 結果発表

- 全ラウンドの記録に、ヒントの使用を射番号つきで載せる。
  > 2射目 チカさんがヒントを使用（ジャンル：有名人）：15ダメージ
- HP推移のグラフは従来どおり（ラウンド終了時点の値）。

### 2.5 ルール説明・CONFIG

- ルール説明に「ヒント」の節を追加する（代償・回数・全員に見えること・取り消せないこと）。数値は CONFIG から差し込む。
- CONFIG に「ヒントのダメージ」（0〜99、初期値 15）を追加する。
  - ヒントの回数は 1ゲーム1回で固定し、CONFIG の項目にはしない（持ち主の判断）。

## 3. ジャンル一覧

選択式。粒度をそろえるため、辞書のカテゴリ（40）とは別に次の 16 ジャンルを持つ。不足があれば追加する。

| ジャンル id       | 表示名             | 対応する辞書カテゴリ                                                     |
| ----------------- | ------------------ | ------------------------------------------------------------------------ |
| japan-place       | 日本の地名         | 都道府県、県庁所在地、日本の有名な地名                                   |
| world-place       | 世界の国・都市     | 国名、世界の首都                                                         |
| landmark          | 建物・名所         | 日本の名所・建物、世界の名所                                             |
| landform          | 山・川・海         | 日本の山、日本の川、日本の湖、海・湾・海峡、世界の山、世界の川、世界の湖 |
| historical-person | 歴史上の人物       | 日本の歴史上の人物、世界の歴史上の人物                                   |
| celebrity         | 有名人             | 芸能人、スポーツ選手・棋士、内閣総理大臣（2000年以降）                   |
| creature          | 生き物             | 動物、鳥、虫、海や川の生き物                                             |
| plant             | 植物               | 花・植物                                                                 |
| food              | 食べ物・飲み物     | 果物、野菜、料理、お菓子・デザート、飲み物                               |
| vehicle           | 乗り物             | 乗り物                                                                   |
| tool              | 道具・日用品       | 文房具・学用品、日用品・家具、家電、スポーツの道具                       |
| clothing          | 服・身につけるもの | 服・身につけるもの                                                       |
| play-music        | 楽器・おもちゃ     | 楽器、遊具・おもちゃ                                                     |
| facility          | 建物・施設（一般） | 建物・施設                                                               |
| nature            | 自然・天体         | 天体・自然                                                               |
| tradition         | 行事・伝統         | 伝統・行事のもの                                                         |

- 「その他」は置かない（曖昧なヒントを防ぐ）。
- ジャンルの表示名は多言語化の対象（`src/locales/<lang>.json`）。id はコードと辞書で共通。

## 4. データ・実装の変更点（見込み）

| 対象                   | 変更                                                                                                                                                                        |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 辞書の形式（SPEC 5.1） | カテゴリに `genre`（上の id）を追加する。`genre` がない・未知のカテゴリは、読み込み時に警告を出してランダム出題から除外する。形式の `version` は 1 のまま（項目の追加のみ） |
| 同梱の辞書             | 40 カテゴリすべてに `genre` を付ける。検査テストに「全カテゴリに既知のジャンルがある」を追加                                                                                |
| CONFIG                 | `hintDamage`（0〜99、初期値 15）。回数は 1 回固定で CONFIG にしない                                                                                                         |
| ゲーム状態             | お題に `genre` を追加。プレイヤーごとの「ヒント使用済み」、ラウンドごとの「公開したジャンル」を追加。記録（ShotEvent）に `hint` 種別（射番号・使った人・ダメージ）を追加    |
| 保存データ             | 形が変わるので `GAME_SCHEMA_VERSION` を 2 に上げる（進行中の古いデータは破棄して通知される）                                                                                |
| 状態機械               | `useHint` アクション。ダメージ（倍率なし）、脱落判定、取り消し不可（undo を消す）、同じラウンドで2回目は無効                                                                |
| 画面                   | 出題（ジャンル選択）、承認（ジャンル表示）、射撃（ヒントボタン・確認ダイアログ・ジャンル表示・持っている印）、結果発表（記録）                                              |
| テスト                 | 状態機械（ダメージ・倍率なし・回数・脱落・取り消し不可・同じラウンドで無効）、辞書のジャンル、画面（確認ダイアログ・表示・秘匿の検査）                                      |

## 5. 変えないもの

- 誤射ダメージは 5 のまま（固定。ターンごとに増やす案は見送り）。
- 命中・誤射の倍率（延長戦 2 倍、サドンデス 1 倍）は従来どおり。
